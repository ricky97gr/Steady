---

## 1. 项目概述

### 1.1 项目定位

构建一个**个人量化研究与模拟交易平台**，实现从行情数据获取 → 策略计算 → 模拟交易 → 收益分析的完整闭环。

### 1.2 设计原则

| 优先级 | 原则 |
|--------|------|
| 第一原则 | 数据可靠 > 策略复杂 |
| 第二原则 | 可解释策略 > 黑盒模型 |
| 第三原则 | 模拟验证 > 实盘尝试 |
| 第四原则 | 长期复利 > 短期暴利 |

### 1.3 V1.0 不做的事

- ❌ 高频交易
- ❌ 自动盈利
- ❌ AI 预测涨跌
- ❌ 复杂机器学习
- ❌ Kafka / 消息队列
- ❌ Kubernetes 集群
- ❌ 微服务拆分
- ❌ 实时 Tick 数据
- ❌ 复杂权限系统

## 2. 整体架构

```
                     A股数据源
          AkShare / Tushare / 券商接口
                          |
                          v
                   Data Collector (Python)
                          |
                          v
                      PostgreSQL
                          |
          +---------------+---------------+
          |                               |
    Quant Engine                   Backend Service
      (Python)                   Go (API + 模拟交易)
          |                               |
          +---------------+---------------+
                          |
                    React Dashboard
                TypeScript + Ant Design
```

### 2.1 服务职责划分

| 服务 | 语言 | 核心职责 |
|------|------|----------|
| Data Collector | Python | 数据采集、清洗、入库、历史回填 |
| Quant Engine | Python | 因子计算、策略执行、回测（批处理任务，无 HTTP 服务） |
| Backend Service | Go | 统一 HTTP 接口 + 模拟交易（账户、订单、持仓、净值快照） |
| Dashboard | React/TS | 数据展示、策略管理、交易查看 |

### 4.3 分支管理策略

| 分支 | 用途 | 保护规则 |
|------|------|----------|
| `main` | 生产就绪的稳定代码 | 受保护，仅通过 PR 合并 |
| `develop` | 日常集成分支 | 受保护 |
| `feature/*` | 新功能开发 | 从 `develop` 拉出，合回 `develop` |
| `hotfix/*` | 紧急修复 | 从 `main` 拉出，合回 `main` 和 `develop` |

### 4.4 Commit 规范

采用 Conventional Commits 规范：

```
<type>(<scope>): <description>

[optional body]

[optional footer]
```

**Type 列表：**

| Type | 说明 |
|------|------|
| feat | 新功能 |
| fix | Bug 修复 |
| docs | 文档变更 |
| style | 代码格式（不影响逻辑） |
| refactor | 重构（非新功能、非修复） |
| perf | 性能优化 |
| test | 测试相关 |
| chore | 构建/工具链变更 |

**示例：**

```
feat(collector): 添加每日行情自动采集任务
fix(api): 修复股票详情接口空数据报错
docs(readme): 更新部署说明
```

## 5. 数据库详细设计

### 5.1 ER 关系概览

```

stock_basic (1) ──────< (N) daily_price
     │
     │
     └──────< (N) financial_indicator
     │
     └──────< (N) factor_value
                   │
                   v
            factor_definition (1)
     │
     └──────< (N) strategy_signal
                   │
                   v

     │
     └──────< (N) order
     │              └──────< (N) trade
     └──────< (N) account_nav
```

|------|------|------|------|
| code | VARCHAR(10) | PRIMARY KEY | 股票代码 |
| name | VARCHAR(50) | NOT NULL | 股票名称 |
| market | VARCHAR(10) | | 市场（SH/SZ/BJ） |
| industry | VARCHAR(50) | | 所属行业 |

### 7.3 采集器基类设计

```python
# collector/app/collectors/base.py
from abc import ABC, abstractmethod
import logging
import time

class BaseCollector(ABC):
    """采集器基类，统一异常处理和重试逻辑"""

    max_retries = 3
    retry_delay = 5  # seconds

    def __init__(self, db_session):
        self.db = db_session
        self.logger = logging.getLogger(self.__class__.__name__)

    @abstractmethod
    def fetch(self, *args, **kwargs):
        """从数据源拉取数据"""
        pass

    @abstractmethod
    def save(self, data):
        """保存数据到数据库"""
        pass

    def run(self, *args, **kwargs):
        """执行采集（带重试）"""
        for attempt in range(self.max_retries):
            try:
                data = self.fetch(*args, **kwargs)
                self.save(data)
                self.logger.info(f"采集成功: {len(data)} 条")
                return True
            except Exception as e:
                self.logger.warning(f"第{attempt+1}次重试: {e}")
                time.sleep(self.retry_delay)
        self.logger.error(f"采集失败，已达最大重试次数")
        return False
```

### 7.6 历史数据回填

**目的：** 因子计算与回测需要多年历史行情，仅靠每日增量不够。

**策略：**

- 只回填股票池（沪深300 + 中证500，约 800 只）的日行情与财务数据，不拉全市场
- 分批拉取（每批 50-100 只），控制请求频率（如 3 秒/只），避免触发 AkShare 限速
- 断点续传：进度记录表（或本地 checkpoint 文件），中断后从上次位置继续
- 回填完成后校验：每只股票行数 ≈ 上市日~今日的交易日数，缺失日自动补齐
- 回填建议放在上线第一个周末执行，不影响日常增量任务

### 7.7 数据质量校验规则

采集入库前统一执行（`collector/app/cleaners/`）：

| 规则 | 校验内容 | 处理 |
|------|----------|------|
| 唯一性 | `(code, trade_date)` 不重复 | UPSERT 去重 |
| OHLC 一致性 | `high >= max(open, close)`，`low <= min(open, close)` | 异常丢弃并告警 |
| 价格边界 | `open/high/low/close > 0` | 异常丢弃 |
| 涨跌幅边界 | `|涨跌幅| <= 涨跌停幅度`（主板 10%，创业板/科创板 20%，北交所 30%） | 超限告警并人工复核 |
| 成交校验 | `volume > 0`（停牌日无成交记录） | 停牌日不入库 |
| 财务校验 | 同一 `(code, report_date)` 重复时取 `announce_date` 最新 | 增量更新 |

## 8. 策略框架设计

### 8.1 设计原则

**策略不能写死，要可插拔。**

所有策略继承统一基类，实现固定接口，便于：
- 新增策略不改主流程
- 多策略并行运行
- 回测结果可对比

### 8.2 策略基类

```python
# quant-engine/app/strategies/base.py
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import List, Optional
import pandas as pd

@dataclass
class Signal:
    """策略信号"""
    code: str
    score: float
    action: str  # BUY / SELL / HOLD
    reason: str

class Strategy(ABC):
    """策略基类"""

    name: str = "base"
    description: str = ""

    def __init__(self, config: dict):
        self.config = config
        self.logger = logging.getLogger(f"strategy.{self.name}")

    @abstractmethod
    def prepare(self, trade_date: str) -> None:
        """
        准备阶段：加载数据、初始化环境
        - 拉取行情数据
        - 加载因子值
        - 准备候选股票池
        """
        pass

    @abstractmethod
    def calculate(self) -> pd.DataFrame:
        """
        计算阶段：执行策略核心逻辑
        - 计算因子得分
        - 综合评分
        - 排序筛选
        """
        pass

    @abstractmethod
    def generate_signal(self) -> List[Signal]:
        """
        生成阶段：输出买卖信号
        - 根据评分生成 BUY/SELL/HOLD
        - 附带原因说明
        """
        pass

    def run(self, trade_date: str) -> List[Signal]:
        """标准执行流程"""
        self.prepare(trade_date)
        self.calculate()
        return self.generate_signal()
```

```python
import pandas as pd
import numpy as np

def ma_trend(close: pd.Series, short=5, long=20) -> pd.Series:
    """均线趋势因子：MA5 > MA20 为正"""
    ma_short = close.rolling(short).mean()
    ma_long = close.rolling(long).mean()
    return (ma_short > ma_long).astype(int)

def macd_signal(close: pd.Series) -> pd.Series:
    """MACD 信号因子"""
    ema12 = close.ewm(span=12).mean()
    ema26 = close.ewm(span=26).mean()
    dif = ema12 - ema26
    dea = dif.ewm(span=9).mean()
    return (dif > dea).astype(int)
```

### 9.2 Portfolio 设计

```python
# quant-engine/app/backtest/portfolio.py
from dataclasses import dataclass, field
from typing import Dict

@dataclass
class Position:
    code: str
    quantity: int
    available_qty: int   # T+1：当日买入冻结，次一交易日解冻
    cost_price: float
    current_price: float

    @property
    def market_value(self) -> float:
        return self.quantity * self.current_price

    @property
    def profit(self) -> float:
        return self.quantity * (self.current_price - self.cost_price)

@dataclass
class Portfolio:
    initial_cash: float = 100000.0
    cash: float = field(default_factory=lambda: 100000.0)
    positions: Dict[str, Position] = field(default_factory=dict)
    trades: list = field(default_factory=list)

    @property
    def total_value(self) -> float:
        mv = sum(p.market_value for p in self.positions.values())
        return self.cash + mv

    @property
    def total_return(self) -> float:
        return (self.total_value - self.initial_cash) / self.initial_cash

    def buy(self, code: str, price: float, qty: int, commission: float):
        if qty % 100 != 0:
            raise ValueError("买入数量必须为100股整数倍")
        cost = price * qty + commission
        if cost > self.cash:
            raise ValueError("资金不足")
        self.cash -= cost
        if code in self.positions:
            pos = self.positions[code]
            total_cost = pos.cost_price * pos.quantity + price * qty
            pos.quantity += qty
            pos.cost_price = total_cost / pos.quantity
            # T+1：当日买入部分冻结，由引擎在次一交易日解冻
            pos.frozen_qty = getattr(pos, 'frozen_qty', 0) + qty
        else:
            # T+1：新建仓当日 available_qty = 0
            self.positions[code] = Position(code, qty, 0, price, price)

    def sell(self, code: str, price: float, qty: int, commission: float, tax: float):
        if code not in self.positions:
            raise ValueError("无持仓")
        pos = self.positions[code]
        if qty > pos.quantity:
            raise ValueError("持仓不足")
        proceeds = price * qty - commission - tax
        self.cash += proceeds
        pos.quantity -= qty
        if pos.quantity == 0:
            del self.positions[code]
```

### 9.3 Broker 设计

```python
# quant-engine/app/backtest/broker.py
class Broker:
    """模拟券商成交"""

    COMMISSION_RATE = 0.00025   # 万2.5
    MIN_COMMISSION = 5.0        # 最低5元
    STAMP_TAX_RATE = 0.0005     # 印花税 万5（仅卖出）
    SLIPPAGE = 0.001            # 滑点 0.1%

    def calc_commission(self, amount: float) -> float:
        return max(amount * self.COMMISSION_RATE, self.MIN_COMMISSION)

    def calc_tax(self, amount: float) -> float:
        return amount * self.STAMP_TAX_RATE

    def _check_price_limit(self, code: str, price: float, prev_close: float, direction: str) -> bool:
        """涨跌停检查：涨停买不进、跌停卖不出
        幅度按板块：主板 ±10%，创业板/科创板 ±20%，北交所 ±30%，ST ±5%"""
        limit = self._limit_ratio(code)  # 按板块取涨跌停幅度
        if direction == 'BUY' and price >= prev_close * (1 + limit):
            return False
        if direction == 'SELL' and price <= prev_close * (1 - limit):
            return False
        return True

    def execute_buy(self, portfolio: Portfolio, code: str, price: float, qty: int,
                    prev_close: float = None) -> bool:
        if prev_close and not self._check_price_limit(code, price, prev_close, 'BUY'):
            return False  # 涨停无法成交，跳过
        exec_price = price * (1 + self.SLIPPAGE)
        commission = self.calc_commission(exec_price * qty)
        portfolio.buy(code, exec_price, qty, commission)
        return True

    def execute_sell(self, portfolio: Portfolio, code: str, price: float, qty: int,
                     prev_close: float = None) -> bool:
        if prev_close and not self._check_price_limit(code, price, prev_close, 'SELL'):
            return False  # 跌停无法成交，跳过
        exec_price = price * (1 - self.SLIPPAGE)
        commission = self.calc_commission(exec_price * qty)
        tax = self.calc_tax(exec_price * qty)
        portfolio.sell(code, exec_price, qty, commission, tax)
        return True
```

### 9.4 回测引擎主循环

```python
# quant-engine/app/backtest/engine.py
class BacktestEngine:
    """回测引擎"""

    def __init__(self, strategy: Strategy, start_date: str, end_date: str):
        self.strategy = strategy
        self.start_date = start_date
        self.end_date = end_date
        self.portfolio = Portfolio(initial_cash=100000)
        self.broker = Broker()
        self.daily_returns = []

    def run(self):
        dates = self._get_trading_dates()
        for date in dates:
            self._unfreeze_t1(date)  # T+1：解冻上一交易日买入
            signals = self.strategy.run(date)
            for signal in signals:
                self._process_signal(signal, date)
            # 记录每日净值（含回撤与基准对比）
            nav = self.portfolio.total_value
            benchmark = self._get_benchmark_nav(date)  # 沪深300 同期净值
            self.daily_returns.append({'date': date, 'nav': nav, 'benchmark': benchmark})
        return self._generate_report()

    def _process_signal(self, signal, date):
        if signal.action == 'BUY':
            price = self._get_price(signal.code, date)
            qty = self._calc_quantity(price)  # 等权 + 单股仓位上限
            # 涨停检查 + 100股整手 + 资金校验（Broker 内完成）
            self.broker.execute_buy(self.portfolio, signal.code, price, qty,
                                    prev_close=self._get_prev_close(signal.code, date))
        elif signal.action == 'SELL':
            price = self._get_price(signal.code, date)
            pos = self.portfolio.positions.get(signal.code)
            if not pos or pos.available_qty <= 0:  # T+1：当日买入不可卖
                return
            self.broker.execute_sell(self.portfolio, signal.code, price, pos.available_qty,
                                     prev_close=self._get_prev_close(signal.code, date))
```

> **回测与模拟交易一致性要求：**
> - 费率、滑点、涨跌停规则必须与 Backend Service（Go）的 trade 模块完全一致
> - 配置单一来源：两处都读取同一份 `config.yaml`（`account.commission_rate` 等）
> - 交付前跑一致性对照测试：同一历史数据上，Python 回测与 Go 模拟的每日净值偏差 < 0.1%

```python
            "level": record.levelname,
            "module": record.module,
            "message": record.getMessage(),
```

```
Step 5: React Dashboard（HTTP → 可视化）
    ↓
Step 6: Go Backend Service trade 模块（信号 → 模拟交易 → 闭环）
```

**原因：** 量化系统的核心资产是**数据和策略逻辑**，不是页面。工程能力强的地方可以后做，数据和策略必须先通。

## 18. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| AkShare 接口不稳定 | 数据采集中断 | Tushare 备选 + 重试机制 + 告警通知 |
| 历史数据回填耗时 | 项目延期 | 仅回填股票池 + 分批限速 + 断点续传 |
| 数据质量问题 | 策略信号失真 | 数据清洗 + 异常检测 + 人工抽检 |
| 财务因子未来函数 | 回测结果虚假 | 因子只按公告日取值 + 样本外验证 |
| 回测与模拟逻辑漂移 | 回测收益不可信 | 费率单一配置源 + 一致性对照测试 |
| 策略过拟合 | 回测好看实盘亏 | 样本外验证 + 多周期测试 + 简单优先 |
| Docker 容器崩溃 | 服务中断 | 健康检查 + 自动重启 + 日志告警 |
| 数据库膨胀 | 查询变慢 | 分区表 + 定期归档 + 索引优化 |
| 密码/Token 泄露 | 安全事故 | 环境变量 + .env 不进 Git + 定期轮换 |

## 19. V1.0 验收标准

系统每天自动完成以下闭环：

```
✅ 1. 获取 A 股行情（收盘后自动采集，含交易日历）
✅ 2. 更新数据库（行情 + 财务，数据质量校验通过）
✅ 3. 计算股票评分（因子加权，横截面归一化）
✅ 4. 输出买卖信号（BUY/SELL/HOLD，轮动规则）
✅ 5. 模拟交易执行（自动下单 + 成交，含涨跌停/T+1/整手校验）
✅ 6. 更新账户收益（现金 + 持仓 + 盈亏）
✅ 7. 展示收益曲线（Dashboard 可视化，对比沪深300）
✅ 8. 数据质量校验通过（OHLC 一致性、涨跌幅边界、去重）
✅ 9. 回测与模拟交易费率/成交规则一致（对照测试通过）
```

**全部达成 → V1.0 完成。**
