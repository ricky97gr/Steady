# 个人 A 股量化交易系统 V1.0 最终设计方案

## 1. 项目定位

### 目标

构建一个个人量化研究与模拟交易平台。

第一版核心目标：

> 完成从行情数据 → 策略计算 → 模拟交易 → 收益分析的完整闭环。

不追求：

- 高频交易
- 自动盈利
- AI预测涨跌
- 复杂机器学习

重点：

- 数据积累
- 策略验证
- 交易纪律
- 系统工程能力

### 4.2 Quant Engine

#### 语言

Python

#### 职责

负责：

- 因子计算
- 股票评分
- 策略生成

结构：

```
quant-engine
├── factor
├── strategy
├── backtest
└── risk
```

---

#### 第一版策略

采用：

**多因子评分模型**

评分：

```
总分 = 趋势因子 40% + 价值因子 30% + 质量因子 20% + 风险因子 10%
```

**股票池：** 沪深300 + 中证500 成分股（约 800 只），横截面排名打分

**调仓规则：** 每日排名，等权买入前 20；持仓跌出前 30 卖出（缓冲带防止频繁换手）；单股仓位上限 20%

**数据口径：** 财务因子按公告日（announce_date）对齐，防止未来函数；因子计算用前复权价，模拟交易用真实价

---

#### 输出

每天生成：

```
strategy_signal
- 股票代码
- 评分
- 建议: BUY / SELL / HOLD
```

## 5. 数据流程

### 每日流程

```
上线首日    →  回填股票池历史行情（分批、断点续传）
交易日 16:30  →  同步行情（等数据源就绪）
    18:00     →  更新数据库
    18:30     →  计算因子
    19:00     →  生成策略信号
    20:00     →  模拟交易
    21:00     →  生成日报
```

## 9. V1.0 验收标准

系统每天自动完成：

```
1. 获取A股行情（含交易日历、股票池回填）
2. 更新数据库（数据质量校验通过）
3. 计算股票评分（横截面归一化）
4. 输出买卖信号（轮动规则）
5. 模拟交易（A股规则：涨跌停 / T+1 / 整手）
6. 更新账户收益（含每日净值快照）
7. 展示收益曲线（对比沪深300）
8. 回测与模拟交易费率/成交规则一致（对照测试通过）
```

**可解释策略 > 黑盒模型**

### 第三原则

**模拟验证 > 实盘尝试**
