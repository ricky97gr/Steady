# 金融 / 量化术语表

> 面向个人投资者的口径，每词 1-2 句。供 Steady 平台「术语解释」能力使用。

## 估值类

- **PE（市盈率）**：股价 ÷ 每股收益，衡量「多少年回本」。PE 低常见于低估或基本面差，PE 高常见于高成长或泡沫，须结合行业看。
- **PB（市净率）**：股价 ÷ 每股净资产，衡量「为账面资产付几倍价格」。重资产行业（银行/地产）常用 PB 估值。
- **ROE（净资产收益率）**：净利润 ÷ 净资产，衡量公司用股东的钱赚钱的效率，长期 ROE 稳定偏高的公司往往质地好。
- **股息率**：每股分红 ÷ 股价，衡量「买股票每年能收多少息」，高股息股偏防御。
- **PE-TTM**：用最近 12 个月滚动利润算的市盈率，比静态 PE 更能反映当前盈利水平。

## 交易类

- **T+1**：A 股当日买入的股票次日才能卖出；资金卖出后当日可再买。
- **涨停 / 跌停**：交易所设的单日价格涨跌上限（主板 10%、创业板/科创板 20%、北交所 30%、ST 5%），触及后通常难以成交。
- **换手率**：当日成交量 ÷ 流通股本，反映筹码换手活跃度，过高常伴随剧烈波动。
- **印花税**：A 股卖出时征收的交易税费（当前万 5），只在卖出收；买入不收。
- **滑点**：实际成交价与期望价的差值，小盘股/大单时更明显，回测中一般按固定比例模拟。
- **连板**：连续多个交易日涨停，情绪指标之一，连板高度代表短线投机热度。
- **资金流**：按成交主动性把买卖盘分为主力/散户资金净流入流出，是观察资金动向的参考（但非决定信号）。

## 风险与收益类

- **最大回撤**：账户净值从历史高点跌到低点的最大幅度，衡量「最坏时候亏多少」，回撤越小持有体验越好。
- **夏普比率**：（年化收益 − 无风险利率）÷ 波动率，衡量「每承担一单位波动换来多少超额收益」，越高越好。
- **Alpha（α）**：跑赢基准（如沪深 300）的超额收益，衡量策略/选股本身的水平。
- **Beta（β）**：相对大盘的波动敏感度，β>1 比大盘更颠簸，β<1 更抗跌。
- **波动率**：收益率的波动幅度，常用标准差衡量，是风险的核心度量。

## 指数与市场类

- **宽基指数**：覆盖全市场多个行业、代表性强的指数，如沪深 300、中证 500、上证 50，适合作为基准或定投标的。
- **行业轮动**：资金在行业间切换的节奏（顺周期/科技/消费/医药轮着涨），量化中常作为风格配置因子。
- **情绪周期**：市场从冰点→回暖→亢奋→退潮的循环，用于判断短线参与时点。
- **抱团 / 拥挤度**：资金集中押注少数板块或个股的程度，过度拥挤后易踩踏。

## 量化 / 因子类

- **因子**：能解释收益来源的可度量特征，如价值（低 PE/PB）、成长（利润增速）、质量（高 ROE）、动量（近期涨幅）。
- **多因子模型**：把多个因子打分加权合成一个综合评分，再按分选股，是主流量化选股框架。
- **动量（momentum）**：强者恒强，近 N 日涨幅高的股票倾向于继续涨；与之相对的是反转（超跌反弹）。
- **因子暴露 / 因子中性**：组合在某因子上敞口的大小；中性化即把该因子影响剥离后再比较。
- **过拟合 / 未来函数（look-ahead bias）**：策略在历史数据上「看得到未来」或用太多次数据调参导致的虚假优秀，是回测最大的坑。
- **样本外 / 滚动回测**：用未见过的数据验证策略，比全样本回测可信。

## 仓位与操作类

- **仓位**：投入股市的资金占总资金的比例，控制仓位是控制风险的第一步。
- **止损 / 止盈**：设定价格，跌到止损位割肉防大亏，涨到止盈位兑现，机械执行避免情绪干扰。
- **网格 / 定投**：定时定额买入或按价格档位分批买卖，用纪律摊平成本。
- **复权**：把除权除息影响加回价格序列，分前复权/后复权，回测和看趋势必须用复权价。
